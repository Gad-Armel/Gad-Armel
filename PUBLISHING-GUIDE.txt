# Publish your GitHub profile

1. Open https://github.com/Gad-Armel/Gad-Armel
2. Choose **Add file → Upload files**.
3. Upload `README.md`, the `assets` folder (including `profile-banner.svg`), and `beauty-salon-dashboard-preview.html`.
4. Commit the changes to the `main` branch.
5. Open your profile at https://github.com/Gad-Armel to review it.

The README links the flyer to `flyer.pdf`. When you provide the flyer, add it to the repository root with that exact filename, or update the link.
The phone button is a placeholder because no public phone number has been supplied. Replace `tel:` with `tel:+1...` and edit its badge label if you want your number public.
